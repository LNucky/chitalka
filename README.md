# Читалка

Личная mobile-first читалка для Safari на iPhone и современных настольных браузеров. Статический HTML, CSS и JavaScript. Движок foliate-js включён в исходники, сборка и сервер приложений не требуются.

## GitHub Pages

1. Создай репозиторий, например `chitalka`. На GitHub Free выбери публичный репозиторий.
2. Помести содержимое папки проекта в корень ветки `main`. Сохрани файл `.nojekyll` и папку `vendor`.
3. Открой **Settings → Pages → Deploy from a branch → main → / (root)** и нажми **Save**.
4. Открой адрес `https://<логин>.github.io/chitalka/` на iPhone. Нажми **Добавить книгу** и выбери файл в «Файлах».

Локальный запуск из папки проекта: `python3 -m http.server 8000`, затем открой `http://localhost:8000/`.

## Как устроено

- Полка и экран чтения. Листание кнопками, жестами движка и стрелками клавиатуры. Оглавление, размер текста и три темы.
- EPUB без DRM, FB2 и ZIP с одним FB2. Лимит файла 64 МБ, распакованного архива 128 МБ. Настройки текста рассчитаны на книги с адаптивной версткой.
- IndexedDB хранит файл, метаданные и позицию CFI. Книга определяется по SHA-256 её содержимого. FB2 и архив с этим же FB2 считаются одной книгой.
- Каждое перемещение сохраняет позицию. Через «Перенести прогресс» можно скачать JSON и импортировать его на другом устройстве. При совпадении книги берётся более свежая запись. Добавь на втором устройстве тот же файл книги.
- GitHub Pages отдаёт код читалки. Импортированные файлы и прогресс остаются в браузере. При очистке данных сайта локальная полка и позиции удаляются.
- Автоматическая синхронизация между устройствами потребует отдельного API с авторизацией и хранилищем. PDF можно добавить отдельным этапом.
